# "To: My Heart" — cute React letter

Tiny Vite + React project that shows a love-letter front screen with floating hearts and a centered greeting.

Quick start (Windows PowerShell):

```powershell
npm install
npm run dev
```

Open the URL printed by `vite` (usually `http://localhost:5173`).

Notes:
- If `npm install` fails, ensure you have a modern Node.js (v18+) and npm installed.
- This project uses Vite; dependencies are in `package.json`.
